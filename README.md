课题描述：实现一款基于STM32F103RCT6的智能交互屏幕，负责从方案设计、硬件选型到代码实现的全流程开发。通过编码器旋钮
与按键的组合操作，设计有限状态机实现多级菜单的选中、切换与进入，实现四个核心功能的流畅切换。
· 驱动ESP8266通过UART与MCU通信，基于MQTT协议获取网络标准时间，并对本地RTC时钟进行校准，用于显示北京时间。通过
I2C总线驱动温湿度传感器，实时采集环境数据，并设计均值滤波算法提升数据稳定性。
· 独立编程实现了计数器应用（支持暂停、继续与复位），用于学习时间记录等场景；同时开发了设备基本信息显示界面。
· 驱动0.96寸OLED屏，设计GUI界面实时展示菜单选项、北京时间、环境参数及设备信息，交互响应时间优化在4s以内完成所有功
能的同步刷新。
